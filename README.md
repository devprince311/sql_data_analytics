# Job Market Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing job market data to identify **high-paying roles, in-demand skills, and optimal career opportunities** using advanced SQL techniques. The analysis is designed to support data-driven decisions for job seekers, analysts, and business stakeholders by uncovering trends across job titles, companies, salaries, and skill requirements.

---

## 🎯 Objectives
- Identify the **most in-demand skills** across analyst and product roles  
- Determine **highest-paying skills and job roles**  
- Analyze **top companies hiring for specific roles**  
- Find skill combinations that offer the **best balance between salary and opportunity**

---

## 🛠️ Tools & Technologies
- **SQL (PostgreSQL/MySQL compatible)**
- Advanced SQL concepts:
  - Common Table Expressions (CTEs)
  - Nested subqueries
  - Multi-table joins
  - Aggregations and ranking logic

---

## 📂 Project Structure

project_job_data/
│
├── highest_salary_for_skill.sql # Skills associated with the highest salaries
├── most_optimal.sql # Skills offering the best salary-to-opportunity ratio
├── top_companies_for_product.sql # Top companies hiring for product-related roles
├── top_skills_analyst.sql # Most in-demand skills for analyst roles
└── top_skills_for_prod.sql # Key skills required for product roles



---

## 📊 Key Insights
- Certain technical and analytical skills consistently command **higher salaries** across roles.
- A small subset of companies dominate hiring for **high-paying product and analyst positions**.
- Some skills provide an **optimal balance of salary and job availability**, making them strategic career investments.
- Skill demand varies significantly between **analyst-focused** and **product-focused** roles.

---

## 🧠 Business Value
This analysis helps:
- Job seekers prioritize skill development
- Analysts understand market demand trends
- Businesses benchmark compensation and hiring strategies

---

## 🚀 How to Use
1. Load the job-related datasets into a SQL database
2. Execute the `.sql` files individually based on the analysis needed
3. Review query outputs to interpret market trends and insights
